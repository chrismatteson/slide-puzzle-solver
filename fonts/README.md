# Fonts

Open-licence fonts (SIL Open Font License 1.1, taken from <https://github.com/google/fonts>, `ofl/`)
used only to render synthetic tile numbers. `train/` feeds classifier training and the training photos;
`eval/` is rendered only by the held-out eval set and is never read by any training code.
The licence text is `OFL.txt`; the copyright notice of every font file is in `COPYRIGHTS.md`. Keep both
when copying these fonts elsewhere.
